# R2 Drop-First 実装計画

> 作成: 2026-04-03
> 目的: 動画をプレイヤーへドロップするだけで、パイプラインが一気通貫で実行されるUXを段階的に実装する。

---

## ゴール

- ユーザー操作は「動画をドロップ」の1アクション。
- 実行中は同一画面で進捗・失敗理由が確認できる。
- 完了後は字幕ブロック編集画面に自動遷移し、結果が即編集可能。

---

## マイルストーン

1. M1: UI骨格
- 動画Drop時に Pipeline Job を開始するフロント実装。
- 右パネルに Pipeline Status を追加（待機/実行中/成功/失敗）。

2. M2: 一気通貫の最小接続
- 既存SRTを入力に使う暫定ルートで、Drop→実行→字幕反映を通す。
- 失敗時リトライとログ表示を実装。

3. M3: 書き起こし実処理接続
- WhisperX（local/remote provider）で字幕生成。
- 生成結果を字幕ブロックへ反映。

4. M4: 翻訳品質とコスト可視化
- 各ステップの処理時間・入力/出力トークン・推定コストを保存。
- 実行結果に品質指標（CPS違反率、42文字超過率）を表示。

---

## 完了条件（DoD）

- 動画ファイルDrop後、ユーザー操作なしでPipelineが開始される。
- 進捗表示が段階遷移する。
- 完了時に字幕ブロック一覧へ結果反映される。
- 失敗時にエラー理由が画面表示され、再実行ができる。
